# 03 · 核心循环与搜打撤规则

> 文档状态：体验方向已确定，具体数值待原型验证
> 依赖：[产品定位与设计支柱](01-产品定位与设计支柱.md)、[世界观与叙事规则](02-世界观与叙事规则.md)

## 1. 参考方向与边界

搜打撤体验参考《超自然行动组》的轻量合作结构：

> 准备工具 → 进入超自然区域 → 搜索高价值物品 → 应对或躲避怪物 → 背着战利品撤离 → 回家处理所得。

借鉴的是“搜宝、负重取舍、超自然威胁、合作意外和成功搬回宝物”的体验，不复制竞品的具体地图、怪物、物品、UI、数值或文本。

本项目不以以下内容为重点：

- 重度军事拟真；
- 默认 PvP 抢夺；
- 复杂枪械配件和弹药管理；
- 单纯以击杀数量决定收益；
- 强制清空地图后才能撤离。

## 2. 完整单局循环

### 2.1 家园准备

玩家在炉界中：

1. 整理仓库和上局战利品；
2. 修理或更换装备；
3. 购买照明、恢复、钥匙、诱饵等消耗品；
4. 选择空间锚点与目标位面；
5. 单人出发或组成队伍；
6. 确认进入时愿意承担损失的物资。

### 2.2 位面探索

进入位面后：

1. 确认进入点、已知撤离信息和本局规则；
2. 搜索建筑、容器、资源点和隐藏空间；
3. 获得不同价值、体积、重量和风险的回收物；
4. 应对怪物、陷阱、地图变化与环境失稳；
5. 在背包容量、状态、时间与贪欲之间做选择；
6. 决定继续深入、绕路寻找高价值区，或及时返程。

### 2.3 撤离与结算

- 只有成功带回炉界的物品才进入安全库存；
- 玩家可通过普通撤离、特殊撤离或特殊道具离开；
- 多人模式默认允许成员分别撤离；
- 失败时丢失本局所得，并根据难度规则损坏或掉落携入物；
- 结算后玩家处理物资、推进家园并准备下一局。

## 3. 单局节奏：软压力代替统一硬倒计时

默认采用 **危险逐步升级**，不要求所有关卡都有明确倒计时。每张图可按主题调整触发方式。

| 阶段 | 环境表现 | 玩家感受与决策 |
|---|---|---|
| 寂静 | 怪物少、普通区稳定、撤离点可靠 | 确认路线，快速获得基础收益 |
| 活动 | 巡逻增加、灯光异常、部分高价值区开放 | 开始权衡深入与返程 |
| 躁动 | 精英出现、道路变化、假信息增加 | 高收益伴随明显风险 |
| 失稳 | 灰雾推进、地图崩坏、普通撤离点关闭 | 放弃部分物品、寻找最后撤离机会 |

危险度可由多个因素共同推动：

- 在位面中停留的时间；
- 打开的容器和高价值房间数量；
- 拾取危险回收物；
- 制造噪声、破坏建筑或违反规则；
- 击杀某些守卫怪物；
- 激活机关或撤离装置。

原则：危险上升要有可感知信号，避免玩家认为失败毫无预兆。

## 4. 搜索与交互对象

### 4.1 容器

- 宝箱；
- 抽屉、橱柜、货架；
- 木箱、保险柜；
- 墓穴容器；
- 垃圾堆与散落物；
- 怪物巢穴；
- 隐藏夹层。

容器应在搜索耗时、声音、开锁需求、容量和稀有产出上形成差异。

### 4.2 交互建筑

| 类型 | 行为 | 可能结果 |
|---|---|---|
| 宝箱类 | 开启 | 产生随机物品，也可能是拟态陷阱 |
| 可打击建筑 | 击碎 | 掉落材料，同时制造噪声或破坏规则 |
| 门 | 开启、关闭、上锁、破坏 | 改变路线、隔断怪物、暴露房间 |
| 机关 | 激活或修复 | 开启宝藏区、撤离点或事件 |
| 进入点 | 将玩家送入位面 | 登记返回信号 |
| 撤离点 | 等待并完成传送 | 保存当前携带所得 |
| 灯具 | 点亮、携带或熄灭 | 改变安全范围、视野与怪物行为 |

## 5. 回收物规则

### 5.1 核心属性

建议每件回收物至少拥有：

| 属性 | 用途 |
|---|---|
| 价值 | 出售后的基础收益 |
| 体积 | 占用背包格，或要求手持 |
| 重量 | 影响速度、体力或搬运能力 |
| 稳定度 | 是否易碎、污染、衰减或触发异常 |
| 用途标签 | 出售、燃料、材料、制作、研究、展示、锚点 |
| 位面来源 | 决定主题、收购需求、研究或套组 |

具体属性数量需要原型验证，首版应避免过度复杂。

### 5.2 尺寸与搬运

- **小型**：可堆叠或单格收纳，携带方便；
- **中型**：占多个格子，迫使玩家减少补给或其他战利品；
- **大型**：必须抱持，限制攻击、开门或奔跑；
- **协作大型（后续）**：两人搬运，适合联机高价值目标。

大型物品的目的不是单纯增加重量，而是制造“抱着宝物逃跑、队友负责开路”的情境。

### 5.3 多用途取舍

每件有价值的物品可在以下用途之间形成选择：

- 卖给商人；
- 分解成材料；
- 投入炉火；
- 制作装备或建筑；
- 研究并解锁信息；
- 作为家具和收藏展示；
- 特殊锚点用于解锁新位面。

不要求每件物品具备全部用途，但高稀有物不应永远只有“卖掉”一个答案。

### 5.4 危险回收物示例

| 物品 | 收益 | 风险/功能 |
|---|---|---|
| 哭泣玩偶 | 较高价值、可收藏 | 哭声吸引附近怪物 |
| 铜制人头 | 高价值、研究品 | 偶尔指出宝箱，也会制造假标记 |
| 熄灭的长明灯 | 可卖、可展示 | 使用时驱雾，但会消耗自身价值 |
| 无名牌位 | 极高价值 | 拾取后普通撤离暂时失效，需完成仪式 |

## 6. 战斗定位

战斗的目的主要是：

- 为搜索创造空间；
- 保护搬运中的队友；
- 暂时控制追击；
- 获取少量特殊材料；
- 为撤离争取时间。

默认不鼓励把所有怪物清空。部分怪物不会提供值得反复刷取的战利品。

### 6.1 可击退怪物

- 可被普通攻击消灭或暂时击退；
- 用于基础操作、资源消耗和道路压力；
- 可能掉落常见材料，但不应成为主要收益来源。

### 6.2 规则型怪物

直接战斗效率低或无效，玩家需要观察并利用规则。例如：

- 被注视时停止，转身后接近；
- 只攻击携带发光物品的人；
- 依靠脚步和开门声追踪；
- 模仿队友外形或名称；
- 只能被特殊光线驱赶；
- 玩家丢下指定物品后停止追击。

### 6.3 不可正面对抗怪物

用于制造撤退、躲藏和放弃物品的压力。应对方式包括：

- 躲藏与关门；
- 使用诱饵和灯光；
- 丢弃它追踪的物品；
- 利用机关短暂封锁；
- 改变路线并尽快撤离。

此类怪物不掉落常规材料，避免最终被玩家视为普通 Boss。

## 7. 撤离规则

### 7.1 普通撤离

建议每张图至少提供一个初始可理解的撤离方案，并根据地图规模增加备用点。撤离可以要求：

- 启动或修复装置；
- 等待传送稳定；
- 点亮信标；
- 使用钥匙或消耗品；
- 抵挡启动期间的怪物；
- 满足负重或人数限制。

### 7.2 特殊撤离

用于高风险高收益路线，例如：

- 位于高价值区深处；
- 必须携带特定物品；
- 仅限少数人使用；
- 必须多人同步启动；
- 开启后改变地图并吸引大型威胁。

### 7.3 假撤离与规则公平

假撤离可以存在，但必须给出可学习的异常：

- 标记样式不一致；
- 返回信号数量错误；
- 与规则书或场景线索冲突；
- 启动声音、光色或文字存在偏差。

不能用完全无迹可寻的假出口反复没收玩家战利品。

## 8. 失败、倒地与损失

### 8.1 已确定原则

- 本局搜到但尚未撤离的物品属于风险资产；
- 失败必须产生损失，才能支撑搜打撤的紧张感；
- 不采用角色永久死亡；
- 处罚不应重到让轻度玩家因一局失败放弃游戏；
- 多人模式应允许队友救援和带走掉落物。

### 8.2 建议分层

| 内容 | 建议结果 |
|---|---|
| 本局战利品 | 失败后掉落在位面中 |
| 普通消耗品 | 使用即消耗，未使用部分可能掉落 |
| 基础装备 | 损坏并支付修理成本，或低概率掉落 |
| 高风险携入品 | 玩家主动选择是否承担永久掉落风险 |
| 大型回收物 | 直接落在倒地位置，可由队友搬走 |

单人可考虑生成一次性“遗失锚点”，允许玩家尝试回收上局掉落，但该机制尚未确定。

### 8.3 多人倒地

- 先进入可救援的倒地状态；
- 污染或倒地计时持续增加；
- 队友可施救，也可先搬走关键物品；
- 超时后本局失去连接，背包留在原地；
- 不强制所有队友共同成功或失败。

## 9. 多人搜撤基本原则

- 默认合作，不开放 PvP；
- 玩家可以分别撤离；
- 谁携带物品离开，物品进入谁的临时结算；
- 距离较远时不提供完整队友定位；
- 队友名称、外形或信号可能被部分怪物模仿；
- 语音距离衰减属于建议功能，不是首版必需；
- 不复制或生成玩家真实语音，使用角色预设语音、文字或系统信号即可。

多人规则示例：

> 本次登记四名守火者。
> 如果返回信标显示五人，请不要启动传送。

## 10. 炉火压力代替强制业绩配额

游戏不采用固定要求玩家每周期上交多少金额的“上班式配额”。压力来自：

- 炉火持续需要稳定能量；
- 家园扩张需要材料；
- 黑暗入侵前需要准备防御；
- 装备损耗和消耗品需要补充；
- 新锚点和高价值地图需要资源开启。

玩家在雾潮前选择：

- 卖掉回收物购买装备；
- 分解材料建造防御；
- 投入炉火扩大稳定范围；
- 冒险再进行一次搜索；
- 留在家园完成布防。

炉火压力不应在玩家离线时惩罚玩家，详见 [家园炉火与长期成长](04-家园炉火与长期成长.md)。

## 11. 待原型验证参数

- 单局理想时长；
- 背包格数、重量和体积是否同时存在；
- 搜索容器所需时间；
- 危险阶段如何触发；
- 玩家基础攻击能力和瞄准方式；
- 装备的实际掉落与修理比例；
- 普通撤离点数量；
- 多人队伍上限；
- 是否保留单人遗失物回收机会。

这些参数应通过首张地图的连续试玩决定，不应直接沿用旧 Excel 数值。

## 12. 验收问题

首个搜撤原型至少要能回答：

1. 玩家是否会因为看到高价值物品而愿意继续冒险？
2. 背包满时，丢弃哪件物品是否是有意义的选择？
3. 怪物是否迫使玩家改变路线，而不是只扣生命值？
4. 玩家能否在失败前理解自己犯了什么错误？
5. 撤离过程是否比单纯走到出口更紧张？
6. 成功带回宝物后，玩家是否期待立刻再进行一局？
