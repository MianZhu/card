# 04 · 家园炉火与长期成长

> 文档状态：系统关系已确定，数值与生产深度待验证
> 依赖：[世界观与叙事规则](02-世界观与叙事规则.md)、[核心循环与搜打撤规则](03-核心循环与搜打撤规则.md)

## 1. 家园定位

炉界残片既是玩家每局出发与返回的基地，也是长期成长的可视化载体。

家园承担：

- 存储和处理回收物；
- 整备装备和消耗品；
- 选择并激活空间锚点；
- 扩建可用土地；
- 建设功能设施与装饰；
- 接待商人与其他玩家；
- 抵御周期性灰雾入侵；
- 展示玩家探索过哪些位面。

玩家外出搜撤是为了让家园发展，家园发展又让玩家能进入更危险、更富有的位面。

## 2. 炉火系统

### 2.1 三个职责

1. **维持空间**：保持炉界残片的基础稳定；
2. **扩展领土**：为外围稳定节点供能，开放更多建造区域；
3. **转化回收物**：将可燃或可回收物转为炉火能量。

### 2.2 炉火状态

建议不要采用玩家离线时也持续归零的惩罚式消耗。炉火压力主要存在于玩家实际游玩期间和事件中。

| 状态 | 表现 | 玩法影响建议 |
|---|---|---|
| 旺盛 | 光照稳定、范围完整 | 建筑正常，高阶锚点可用 |
| 正常 | 常态运行 | 无额外影响 |
| 微弱 | 火光收缩、边缘起雾 | 部分外围设施效率降低，入侵风险上升 |
| 临界 | 灰雾逼近核心区 | 触发紧急补充或防守事件 |
| 失稳 | 本次防守失败或炉火暂时中断 | 局部区域受损，不永久删除整个存档 |

炉火为零不应直接意味着永久删档。更适合产生一次严重入侵、设施损坏、领土暂时封锁或恢复任务。

### 2.3 能量来源

- 低价值回收物直接投入；
- 专用燃料；
- 位面中的能源核心；
- 建筑生产或能量转化；
- 特殊事件奖励；
- 联机玩家援助。

不同物品可拥有不同的燃烧价值，但“出售价值”和“炉火价值”不必完全等价，以形成取舍。

## 3. 领土扩张

玩家不是从灰雾中凭空造地，而是利用炉火、材料和稳定节点修复炉界原有空间。

扩张流程建议：

1. 修复或放置外围稳定节点；
2. 向节点投入材料与炉火能量；
3. 灰雾后退，显露旧地块、遗迹或空地；
4. 清理污染并完成固定；
5. 新区域加入可建造范围。

扩张可提供：

- 新建筑空间；
- 原生资源点；
- 损坏设施；
- 隐藏地下结构；
- 入侵的新路线；
- 可连接的锚点槽位。

领土越大，需要保护的外围节点越多，不能只提供无代价的线性收益。

## 4. 建筑类型

### 4.1 核心设施

- 中央炉火；
- 规则书/档案台；
- 位面传送装置；
- 主仓库；
- 基础工作台。

### 4.2 生产与整备

- 装备制作与修理台；
- 回收物分解台；
- 研究台；
- 药品或消耗品制作设施；
- 农田、采集或低强度自动生产设施；
- 锚点分析与保存设施。

生产系统的复杂度需要控制，不能盖过搜打撤主循环。稳定生产用于保底，不应替代外出获取稀有物。

### 4.3 交易与社交

- 位面商人联络器；
- 出售/收购设施；
- 玩家交易或公共储物设施；
- 访客传送点；
- 留言或委托板（后续）。

### 4.4 防御设施

- 灯具和稳定灯塔；
- 围墙、门与路障；
- 陷阱；
- 防御塔或自动装置；
- 锚点封锁器；
- 紧急备用光源。

### 4.5 生活与装饰

- 玩家住所；
- 家具、照明、地面与墙面装饰；
- 回收物展柜；
- 不同位面的主题套装；
- 换装与外观设施。

装饰不是完全脱离玩法的附属内容。它可以展示探索成就、提供轻量舒适度或成为玩家互访的主要动力，但不应绑定过强战力。

## 5. 战利品处理闭环

| 处理方式 | 获得 | 牺牲 |
|---|---|---|
| 出售 | 通用货币，可买工具、图纸、家具 | 失去材料和收藏价值 |
| 分解 | 制作与建造材料 | 通常低于完整物价值 |
| 投炉 | 炉火能量和稳定时间 | 无法出售或展示 |
| 制作 | 装备、工具、消耗品、建筑 | 消耗指定物品和配方 |
| 研究 | 图鉴、规则、锚点知识、配方 | 可能消耗或污染样本 |
| 展示 | 家园个性、收藏进度 | 占用空间，无法流通 |
| 激活锚点 | 解锁位面或连接 | 可能增加入侵和维护压力 |

设计目标是让“值钱”不只等于商店价格。

## 6. 仓库系统

仓库提供安全库存，与单局风险背包明确区分。

建议规则：

- 成功撤离后，物品先进入结算区；
- 玩家确认用途后再转入仓库、出售或分解；
- 仓库容量可通过建设扩充；
- 大型物品需要专门地面、货架或展区；
- 核心燃料和必要工具可拥有受保护存储，避免一次事故清空恢复能力；
- 多人世界区分私人、共享和受限容器。

仓库整理可以提供满足感，但不应因过度碎片化材料成为主要负担。

## 7. 商人与交易

玩家建造联络器后，可以联系在锚点网络中活动的位面商人。

商人可提供：

- 基础工具和消耗品；
- 建筑图纸；
- 家具与装饰；
- 特殊锚点情报；
- 当期高价收购物；
- 不同位面的稀有材料。

高价订单用于引导玩家改变探索目标，但不应成为必须完成的周期配额。

商人剧情保持轻量，只需要功能台词、少量来历暗示和偶发异常商品。

## 8. 装备与角色成长

成长优先来自“获得更多应对手段”，而不是无限堆叠基础数值。

装备可影响：

- 搬运和背包能力；
- 移动、体力与噪声；
- 照明和灰雾抗性；
- 开锁、搜索和识别；
- 击退与短暂控制怪物；
- 特定位面规则的适应；
- 救援和多人协作。

换装可与装备外观结合，但不要求首版制作完整角色换装系统。

## 9. 黑暗入侵

### 9.1 触发逻辑

炉火和锚点在位面网络中会产生信号。家园发展越深，连接越多，灰雾越容易找到炉界。

入侵强度可受以下因素影响：

- 炉火与领土等级；
- 已激活锚点数量；
- 最近进入的污染位面；
- 家园在线玩家数；
- 距离上次入侵的游玩时间；
- 仓库中部分危险回收物。

### 9.2 怪物目标

怪物不只攻击玩家，还会：

1. 熄灭外围灯具；
2. 偷取燃料或高价值物；
3. 破坏稳定节点；
4. 污染锚点；
5. 从多条路线接近中央炉火。

这让防守更接近“保卫光源与设施”，而不是单纯清怪。

### 9.3 失败结果

入侵失败建议造成可恢复后果：

- 部分建筑损坏；
- 外围区域暂时被雾覆盖；
- 少量未保护资源被偷走；
- 锚点进入污染状态；
- 触发恢复与清理目标。

不采用炉火归零即永久结束整个存档。

## 10. 无结局的长期目标

### 家园目标

- 扩大和规划领土；
- 建设功能区与防线；
- 收集家具和主题装饰；
- 优化仓储、路线和生产；
- 打造可供朋友参观或共同生活的炉界。

### 探索目标

- 收集更多位面锚点；
- 进入更高污染区域；
- 完成稀有规则组合；
- 获取特殊回收物；
- 发现固定遗迹和异常坐标；
- 完善物品、怪物和规则图鉴。

### 成长目标

- 建立不同装备方案；
- 强化搬运、探索、战斗或支援能力；
- 提高抵抗高级入侵的能力；
- 解锁新的建筑与锚点技术。

### 联机目标

- 互访家园；
- 共同建设共享炉界；
- 交换不同位面物资；
- 组队搬运大型宝物；
- 共同挑战高危位面和大型雾潮。

## 11. 阶段性完成

修复炉界主锚点是长期模式的入口，不是结局。完成后：

- 基础区域稳定；
- 更高级锚点网络开放；
- 黑暗入侵进入可持续难度层级；
- 系统持续产生新坐标和建设需求；
- 玩家可以继续单人或联机发展。

## 12. 已确定 / 待验证 / 暂不做

### 已确定

- 家园是搜撤所得的主要回流目标；
- 炉火、领土、锚点和入侵互相连接；
- 回收物具有多种处理方式；
- 没有真正结局；
- 离线不以燃料归零惩罚玩家；
- 防守失败可恢复，不删除存档。

### 待验证

- 炉火消耗速度；
- 建筑维护是否必要；
- 自动生产的比例；
- 入侵周期与持续时长；
- 仓库容量和材料种类；
- 装饰舒适度是否提供轻量加成。

### 暂不做

- 复杂居民好感与剧情链；
- 大规模自动化工厂；
- 领地被其他玩家 PvP 掠夺；
- 离线时持续消耗燃料并破坏家园。
