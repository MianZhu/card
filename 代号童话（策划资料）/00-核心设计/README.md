## 1. 文档定位

## 2. 当前产品概述

《代号童话》是一款以 **搜打撤、家园建设和长期生存** 为核心的游戏：

- 玩家在自己的“炉界残片”中维持炉火、建设家园；
- 通过空间锚点进入正在崩坏的异位面；
- 搜索回收物，应对或避开怪物，并成功撤离；
- 将战利品用于出售、分解、燃烧、制作、研究或装饰；
- 随着家园成长，应对周期性的灰雾入侵；
- 单人可长期游玩，并为好友联机、共享世界和共同搜撤预留结构。

一句话概括：

> **从正在崩坏的异世界摸宝撤离，再用带回来的东西点亮并扩建自己的位面家园。**

## 3. 已确定的方向

- 美术表现是童话风格，故事本身不是童话书世界。
- 氛围以轻度规则怪谈和克苏鲁式未知为辅，不以压抑剧情为主。
- 采用类似《空洞骑士》的碎片叙事，不设置大量强制对话和跑剧情。
- 搜打撤体验参考《超自然行动组》的轻量合作方向，而不是重度军事 PvP 撤离玩法。
- 游戏没有真正结局；阶段目标只负责解锁玩法和扩大长期目标。
- 灰雾、位面和主角来源不作彻底解释，保留相互矛盾的线索。
- 主角含少量 Meta 元素，但不频繁直接打破第四面墙。
- 每名玩家可拥有独立炉界残片，并可通过锚点连接其他玩家的家园或共同关卡。
- 个人开发优先验证单人最短闭环，再逐步加入联机。

## 6. 文档维护规则

每份专题文档使用以下状态：

- **已确定**：可以作为当前开发依据；
- **建议方案**：方向合理，但需要原型或数值测试；
- **待确认**：存在多个可行答案，尚未决策；
- **暂不做**：不进入当前开发范围，但不代表永久取消。

后续若修改核心规则，应同步更新受影响的专题，并在 [待确认与变更记录](90-待确认与变更记录.md) 中记录日期、变更内容和影响范围。
