## 一、产品定位

**代号童话** 是一款融合 **卡片收集养成 + 搜打撤副本 + 领地经营** 的混合品类休闲游戏。

设计灵感直接来源于腾讯经典网页游戏 **QQ魔法卡片**（2009年发行），将其"抽卡→炼卡→集卡→换卡"的核心循环，与"搜打撤"（Search-Fight-Extract）副本玩法、种植经营玩法进行杂交，形成全新的"资源-行动-成长飞轮"。

### 核心一句话

> 挂机抽卡攒素材 → 炼卡扩张领地/造装备 → 传送门进副本搜打撤 → 回收战利品换资金 → 买图纸变强 → 挑战更深的裂缝

## 二、世界观设定

### 背景：降临

全球各地同时出现不稳定的空间裂隙，将未知的物质、能量和生物映射到地球。受影响最严重的区域被称为 **"异常区"**，物理法则不再可靠。

### 势力

| 组织 | 定位 | 立场 |
|------|------|------|
| 异常区域管理局 | 官方管控与探索机构，玩家雇主 | 中立，关注资源回收与科研 |
| 自由回收者联盟 | 独立回收者的地下网络（交易市场） | 若即若离，可交易情报和装备 |
| 异界狂热者 | 崇拜裂隙能量的神秘组织 | 敌对，试图利用裂隙 |

### 异常区分级

| 辐射等级 | 难度 | 特征 |
|----------|------|------|
| Ⅰ级 | 普通 | 辐射微量，空间稳定，适合新手 |
| Ⅱ级 | 困难 | 辐射低浓度，生物变异显著，视觉干扰 |
| Ⅲ级 | 噩梦 | 辐射中浓度，地形扭曲，电子设备受干扰 |
| Ⅳ级 | 地狱 | 辐射高浓度，空间规则不可靠，视野严重受限 |
| Ⅴ级 | 深渊 | 辐射核心级，仅顶尖特工敢进入 |

### 关键地点

- **中央枢纽** — 管理局大型基地，出发点和归宿（任务大厅、交易所、研发中心、基地入口）
- **迷途之域** — 最早被记录的异常区，辐射等级Ⅰ，新手训练区
- **个人基地** — 玩家被分配的个人异常区，私人领地

## 三、核心循环

```
┌─────────────────────────────────────────────────────────┐
│                    日常挂机层（根基）                       │
│  系统抽卡（每30min）→ 收菜/收炉 → 炼卡扩张领地/造装备      │
└──────────────────────────┬──────────────────────────────┘
                           │ 传送门能量充满
                           ▼
┌─────────────────────────────────────────────────────────┐
│                    副本爆发层（引擎）                       │
│  选裂缝 → 探索/采集 → 遭遇怪物(打/绕/引) → 背包满 → 撤离  │
└──────────────────────────┬──────────────────────────────┘
                           │ 撤离结算
                           ▼
┌─────────────────────────────────────────────────────────┐
│                    经济回收层（闭环）                       │
│  战利品回收换资金 → 商店买图纸 → 造建筑/升级 → 变强 → 再下本 │
└─────────────────────────────────────────────────────────┘
```

### 玩家身份

你是一个"炼金遗孤"，醒来时只记得自己是个游戏策划。手上的"系统"是古代文明留下的"炼金网络终端"。你的优势不是武力，而是对"配方"和"效率"的直觉理解。

### 灵魂天赋（三条成长线）

| 天赋 | 影响 | 升级方式 |
|------|------|----------|
| 感知 | 副本"搜"：隐藏宝箱/稀有矿脉发光提示，满级可见怪物仇恨范围 | 成功撤离副本10次 |
| 共鸣 | 炼卡"炼"：概率暴击(投入3张产出2张)或缩短炼卡时间 | 炼成特定数量的高级卡片 |
| 意志 | 副本"打"+种植"种"：召唤物属性提升，植物生长周期缩短，概率出变种 | 击杀精英怪物或收获稀有植物 |

## 五、各系统详解

### 5.1 抽卡系统

| 项目 | 设定 |
|------|------|
| 免费抽卡 | 每30分钟恢复1次"机会卡"，上限16次 |
| 抽卡产出 | 面值10素材卡80%，面值40占15%，面值150占5% |
| 保底机制 | 每50抽必出1张面值150+卡 |
| 付费抽卡 | 1元=10钻石，单抽100钻，十连抽900钻 |

### 5.2 炼卡系统（核心合成）

| 合成规则 | 耗时 | 产出 |
|----------|------|------|
| 3张面值10 | 1小时 | 1张面值40 |
| 3张面值40 | 4小时 | 1张面值150 |
| 3张面值150 | 12小时 | 1张面值300 |
| 3张面值300 | 24小时 | 1张面值500 |
| 3张面值500 | 48小时 | 1张面值800 |

- 炼卡炉初始1个，可排队（最多排5张）
- 扩展：第2个炉永久解锁500钻石
- 加速：1小时=10钻石

#### 低级卡处理

| 处理方式 | 产出 |
|----------|------|
| 分解 | 面值10→1魔法尘，40→5尘，150→25尘 |
| 尘兑换 | 100尘→面值150自选卡，500尘→面值300自选卡 |
| 出售 | 面值10→100金币，40→500金币，150→2000金币 |

### 5.3 卡牌体系

| 项目 | 设定 |
|------|------|
| 面值体系 | 10、40、150、300、500、800、1200、1800、2400、3200、4000…… |
| 稀有度 | 普通（白）、稀有（蓝）、史诗（紫）、传说（橙） |
| 每套卡数量 | 9~12张（含1~2张高面值稀有卡） |
| 卡牌类型 | 角色卡、建筑卡（可装修）、植物卡（可种植）、素材卡（收集）、技能卡、召唤卡 |
| 卡牌信息 | 名字、星级、合成链条、面值、炼化时间、类型、兑换点数 |

### 5.4 换卡规则

| 项目 | 设定 |
|------|------|
| 交换限制 | 仅限同面值卡片互换 |
| 每日次数 | 5次/天（VIP+3次） |
| 保险箱 | 3个位置，不可被换走（可付费扩至10个） |
| 好友需求 | 每个好友可设置2张"求卡" |

### 5.5 种植系统

种植产出定位为 **"工业原料"和"战略物资"**，而非单纯商品。

| 类别 | 代表产出 | 核心用途 | 回收价 |
|------|----------|----------|--------|
| 粮食类 | 小麦、水稻、土豆 | 炼【基础口粮卡】——召唤物维持费，没口粮会罢工/叛变 | 低（保底收入） |
| 药草类 | 止血草、魔力花 | 炼【初级药水卡】——下副本硬通货，不带药水等于送死 | 中（通常舍不得卖） |
| 经济作物 | 棉麻、橡胶树 | 炼【布料卡】【软管卡】——升级建筑建材 | 中（加工后翻倍） |
| 特殊作物 | 荧光菇、雷击木 | 炼【探照灯卡】【避雷针卡】——应对副本环境DEBUFF | 高（产量极低） |

#### 增值链条示例

种小麦(4h)→收3张小麦素材→炼面粉(10min)→+水素材+糖素材→炼面包卡→回收价=小麦素材单价的5倍

#### 策略机制

- **限时高价收购订单**：每日8点刷新3个订单，引导玩家定向刷副本/开特定卡包
- **新鲜度机制**：收获后新鲜度从100%递减，>80%售价150%，50%-80%售价100%，<50%售价50%且不可炼卡

### 5.6 领地系统

| 领地等级 | 解锁内容 |
|----------|----------|
| 1级（初始1块地） | 1个炼卡炉 + 1个仓库 |
| 5级（5块地） | 哨塔（预警副本怪物强度） |
| 10级（10块地） | 传送门稳定器（锁定副本坐标永久开启） |

- **土地卡合成**：3张土系素材 + 1张水源素材 + 1张风系素材 = 1张可耕种土地卡（30分钟）
- **地块附魔**：用元素素材"施肥"改变地块属性（如火属性地块：炼火系卡时间-20%，种植收获+1）

### 5.7 副本系统（搜打撤核心）

#### 基本参数

- 视角：2D 45°俯视角
- 单局时长：12~16分钟（信号衰减倒计时）
- 死亡惩罚：装备不退还 + 搜刮物全部丢失（角色不永久死亡，被强制传回）

#### 副本类型

| 类型 | 核心目标 | 主要产出 | 风险/策略 |
|------|----------|----------|-----------|
| 探索类（搜） | 生存与采集 | 稀有植物卡、矿物素材、宝箱 | 迷雾限制视野，行动力有限，搜满必须撤 |
| 讨伐类（打） | 战斗与击杀 | 怪物核心(紫素材)、武器卡碎片、大量资金 | BOSS有狂暴时间，需召唤卡+增幅药剂 |
| 秘境类（撤） | 限时跑酷逃生 | 时空沙漏(立即完成炼卡)、特殊建材 | 5分钟倒计时，路上稀有矿+追击怪物，"贪还是不贪" |

#### 裂缝结构类型

| 类型 | 特点 |
|------|------|
| 回路型 | 主路兜回来，适合新手，易找撤离点 |
| 分支型 | 一入口多尽头，撤离点随机刷在某分支 |
| 纵深型 | 越走越深，污染递增，撤离点在最深处 |
| 崩坏型 | 空间不稳定，路径随时间变化 |

#### 撤离机制

- 撤离点 = 出生点（从哪进来从哪出去）
- 回程路动态变化：之前开的门可能被锁、安全区可能刷新怪、迷雾改变地形
- 备用撤离点：地图某处有更难到达的备用点（如Boss区域后面）

#### 怪物系统

**5种行为类型**：

| 类型 | 机制 | 玩家应对 |
|------|------|----------|
| 守卫型 | 守在宝箱前，不巡逻，警戒范围小 | 打（正面突破）/ 引（声音引开） |
| 巡逻型 | 固定路线来回，视野范围大 | 绕（找路线间隙）/ 打（伏击） |
| 召唤型 | 发现玩家后召唤同伴，自身弱 | 速杀（召唤完成前干掉）/ 绕 |
| 区域型 | 不移动，覆盖大片区域远程攻击 | 绕（走位规避）/ 打（冲入近战） |
| 自爆型 | 靠近后自爆，毁周围物资 | 引（引开再跑）/ 远距离击杀 |

**已设计怪物**：土拨鼠、影怪、鬼新娘、大熊、皮鼓、兵俑、巨鲶、蝙蝠、蜘蛛、假人、史莱姆、木偶、僵尸、精绝王后、小熊猫、蛤蟆、鸡蛋仔、凶蛋仔、刺刺蛋、天王、厄狼、地龙、白鼬、丑丑蛋、疯狂的鸽子、大鼬、财神土拨鼠、万圣节假人 等28+种

### 5.8 经济系统

#### 三条金币获取管道

| 渠道 | 核心操作 | 频率 | 风险 | 收益上限 | 适合玩家 |
|------|----------|------|------|----------|----------|
| 种植回收 | 种菜→收获→系统回收 | 低（每天2-4次） | 极低 | 低（稳定但慢） | 佛系/碎片时间 |
| 副本搜打撤 | 进本→采集/战斗→带回→回收 | 高（每小时1-2次） | 高（可能白给） | 极高（欧皇一发） | 肝帝/操作型 |
| 炼卡增值 | 种菜→炼高级卡→卖系统 | 中（取决于炉子） | 中 | 高（差价利润） | 策略型/挂机型 |

#### 金币消耗黑洞

| 消耗方向 | 具体内容 |
|----------|----------|
| 商店特殊图纸 | 自动采集器、双倍炉、龙蛋卷轴碎片（极贵） |
| 传送门充能 | 每次进副本消耗传送能量，可用金币购买（体力机制） |
| 建筑维护费 | 高级建筑随时间损耗，需维修包 |
| 召唤物复活 | 战死召唤物需金币在"英灵殿"复活 |
| 外观/装饰 | 纯个性化，无底洞 |

### 5.9 战斗系统

| 项目 | 设定 |
|------|------|
| 玩家攻击 | 俯视角自由射击（鼠标/摇杆瞄准），单发伤害=1，主要用于触发、引怪、补刀 |
| 技能卡 | 下本前从仓库选4张装入技能槽（火球、冰环、治疗、护盾等），用后消失，由炼卡炉生产 |
| 永久召唤物 | 随行提供被动光环（攻击+20%、防御+15%等），存活24小时，投喂口粮延长 |
| 临时召唤卡 | 副本内消耗品，召唤AI仆从（自动攻击最近敌人），持续60秒 |
| 战斗节奏 | 下本前炼满技能卡和召唤卡 → 副本中射击+丢技能+召唤炮灰 → 撤离结算 → 资源消耗完 → 回领地种田/炼卡 |
