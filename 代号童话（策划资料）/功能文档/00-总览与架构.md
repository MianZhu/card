# 魔法卡片 · 总览与技术架构

> 来源页面：`https://appimg2.qq.com/card/index_v3.html`（本地存档：`魔法卡片-QQ秀.html`）
> 本文档基于本地存档的 HTML/JS 静态代码逆向整理，不含服务端逻辑；服务端 CGI 仅能从前端调用推断。

## 1. 产品定位

**魔法卡片** 是腾讯 QQ 秀旗下的一款网页集卡（收集卡牌）社交游戏。玩家扮演"魔法师"，通过 **抽卡、交换、炼制、偷炉、领取** 等方式收集卡片，集齐"套卡"后获得金币、经验、勋章与免费 QQ 秀奖励。

游戏可运行在两种宿主环境：
- **QQ 秀站点**（`show.qq.com`）——独立页面
- **QQ 空间**（Qzone）——以应用（appid `365`）形式嵌入

## 2. 技术架构

游戏采用 **Flash 本体 + JavaScript 外壳** 的混合架构：

```
┌─────────────────────────────────────────────┐
│  index_v3.html （页面外壳）                    │
│  ┌──────────────┐   ┌──────────────────────┐ │
│  │ Flash 游戏本体 │◄─►│ JS 外壳 (CARD 对象)   │ │
│  │  (swf1)       │   │  弹窗/记录/数据/统计   │ │
│  └──────────────┘   └──────────────────────┘ │
│         ▲                      ▲               │
│         │ ExternalInterface    │ XHR/JSONP     │
│         ▼                      ▼               │
│  ┌────────────────────────────────────────┐  │
│  │ 服务端 CGI: card.show.qq.com/cgi-bin/... │  │
│  └────────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

- **Flash（swf1）**：承载核心玩法画面（魔法屋、卡炉、抽卡动画等），通过 `ExternalInterface` 与 JS 双向通信。
  - JS 调 Flash：`CARD.getFlashObj().xxx()`（如 `gotoPage`、`getMyUserInfo`、`updateInfo`）
  - Flash 调 JS：`CARD.flashCalls.xxx()`（如 `showBox`、`showLevelUp`、`showStoveV3`）
- **JS 外壳**：所有 HTML 弹窗（卡箱、卡炉、商城、任务、礼包等）、社交记录流、数据表管理、统计上报。
- **底层框架**：`QZFL` / `QSFL`（腾讯 QQ 空间前端库 QZone Frontend Library），提供 DOM、事件、Cookie、XHR、JSONP、对话框等基础能力（见 `core.js`）。
