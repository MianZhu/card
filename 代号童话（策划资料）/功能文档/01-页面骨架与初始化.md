## 2. 页面头部脚本（HTML 内联）

- `document.domain = "qq.com"`：统一主域，便于跨子域 iframe 通信。
- 引入顺序：`core.js`（框架）→ `app_sns.js`（SNS 适配）→ `fusion_loader`（Qzone 容器）→ `frameCheck.js` → `api.js` → `cashier.js`（收银台）。
- 页面尾部再引入：`card_comm_v3.js`（逻辑）→ `card_info_v3.js`（数据）→ `badge_info_v3.js`（勋章数据）→ `config2.js`（安全配置）。

## 3. 邀请码回流（HTML 内联）

登录条脚本解析 URL 参数 `Inv_code`，用 32 进制解码后写入 Cookie `zhhd_Invitation_code`（域 `appimg2.qq.com`），用于"拉好友回流"活动的归因：

```js
QSFL.cookie.set("zhhd_Invitation_code", 0, 0, "appimg2.qq.com");
// 命中 Inv_code 时：
QSFL.cookie.set("zhhd_Invitation_code", parseInt(cookiestr, 32), 0, "appimg2.qq.com");
```

## 4. Flash 鼠标滚轮桥接

Flash 无法直接捕获浏览器滚轮事件，页面用 `_onFlashMousewheel` 把滚轮增量转发给 Flash：

```js
fobj.onMouseWheel({ delta: -(wheelDelta/10) });
```

`handleScroll()` / `cancelHandleScroll()` 负责绑定/解绑（兼容 `DOMMouseScroll` 与 `mousewheel`）。

## 5. 初始化流程 `CARD.initIndex(page, env)`

页面底部通过轮询等待 `CARD` 就绪后调用：

```js
(function init(){
  if (typeof(CARD) == 'undefined') setTimeout(init, 500);
  else CARD.initIndex(g_oCardArg.iPage, g_oCardArg.sCardSrc);
})();
```

`initIndex` 主要步骤：

1. **环境判定**：`CARD._bQzone = top.QZONE && top.QZONE.FrontPage ? 1 : 0`，区分 Qzone / QQ 秀，并按 Flash 版本（3/4）上报不同 PGV 埋点。
2. **分享/活动埋点**：Qzone 环境下解析 hash 参数 `type`/`collect`/`sharetype`/`activepgv`/`app_custom`，延时上报 PGV，或触发对应活动弹窗（如 `Freegifts` → `showFreeGiftPage`）。
3. `initEnvironment(env)`：设置 `qqshow` / `qzone` 环境。
4. `checkFlashVersion()`：Flash 低于 `10.0.12` 时替换挂载点为升级引导。
5. **注册流转**：`reg=1` 参数触发新手任务弹窗；`park=2` 触发园区注册弹窗。
6. `CARD.data.init()` + `CARD.data.initTipsData()`：加载数据表与跑马灯提示。
7. **登录态 UI**：据 `CARD._iUin` 切换 `P_LOGIN` / `P_UNLOGIN` 显隐。
8. `addScrollEven()`：绑定滚动懒加载（滚到 `_feed_load_pos=860` 时加载社交记录 `feed.js`）。
9. **延时任务**：
   - `showTips`（5s）跑马灯轮播
   - `loadFeedJs`（5s）加载记录流
   - `CARD.ptp.check`（5s）好友互动提醒
   - `CARD.user.init`（0.1s）加载用户数据
   - `showPresent`（5s）礼物/活动弹窗

## 6. Flash 运行状态守护（HTML 内联）

```js
var flashIsDown = true;
var intervalID = setInterval(checkFlashState, 10000);   // 每 10s 检查
function checkFlashState(){
  if (flashIsDown){                       // Flash 未跑起来
    if (!CARD.getFrom()) CARD.showYinDaoPage();   // 非微端：显示引导页
    else { CARD.hideYinDaoPage(); clearInterval(intervalID); }  // 微端：跳过
  } else { CARD.hideYinDaoPage(); clearInterval(intervalID); }
}
function flashIsRuning(){ flashIsDown = false; }   // Flash 主动回调，停止检查
```

- IE6 未登录时直接跳转 `xui.ptlogin2.qq.com` 登录页。
- 7s 后加载 `ns.js`（通知系统）。
- 每 2s 调 `fusion2.canvas.setHeight` 自适应 Qzone 容器高度。
