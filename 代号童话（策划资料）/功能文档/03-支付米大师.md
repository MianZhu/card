# 03 · 支付系统（米大师 MiniPay）

对应文件：`魔法卡片-QQ秀.html`（内联支付函数）、`cashier.js`

## 1. 概述

游戏内购（购买礼包、魔力/魔火、道具卡、召回令等）通过腾讯 **米大师（Midas）MiniPay** 收银台完成。支付发起由 Flash 触发，JS 侧提供 `midaPay` 桥接函数完成下单与回调分发。

- 收银台脚本：`cashier.js`（`window.midas` 提供 `minipay.buyGoods`）。
- 业务 appid：`1450019115`。

## 2. 支付桥接函数 `midaPay`

```js
function midaPay(url, uin, pf, token, data, sandbox){
  var goodUrl    = decodeURI(url);          // 后台在米大师下单后返回的 goodstokenurl
  var myUin      = uin;                      // openid = uin
  var paypf      = pf;                       // 平台参数 pf
  var skey       = getCookie("skey");        // openkey = skey
  var accessToken= token;
  var sand       = sandbox;                  // 沙箱环境传 1

  window.midas.minipay.buyGoods({
    methods:{
      onSuccess : function(){ finishPay1(data); },  // 支付成功
      onError   : function(code){ errPay1(data); }, // 支付失败
      onNoResult: function(){ closePay1(); },       // 无结果
      onClose   : function(){ closePay1(); },       // 关闭
    }
  },{
    appid       : '1450019115',
    pf          : paypf,
    openid      : myUin,       // uin
    openkey     : skey,        // skey
    session_id  : "uin",
    session_type: "skey",
    sandbox     : sand,        // 沙箱必须传 1
    goodstokenurl: goodUrl,    // 后台下单返回的 url
    native_wxpay: 1            // 支持原生微信支付
  });
}
```

## 3. 支付结果回调（回传 Flash）

三个回调函数把支付结果转发回 Flash 本体（`swf1`）：

```js
function errPay1(data)   { (document.getElementById('swf1')||window['swf1']).errPay(data); }
function finishPay1(data){ (document.getElementById('swf1')||window['swf1']).finishPay(data); }
function closePay1()     { (document.getElementById('swf1')||window['swf1']).closePay(); }
```

## 4. 支付时序

```
Flash 发起购买
   │  (ExternalInterface 调 JS)
   ▼
midaPay(url,uin,pf,token,data,sandbox)
   │  取 skey，组装米大师参数
   ▼
window.midas.minipay.buyGoods(...)     ← cashier.js 提供
   │
   ├─ onSuccess → finishPay1(data) → swf1.finishPay(data)   处理发货/刷新
   ├─ onError   → errPay1(data)    → swf1.errPay(data)
   ├─ onNoResult→ closePay1()      → swf1.closePay()
   └─ onClose   → closePay1()      → swf1.closePay()
```

## 5. 相关支付/开通入口（card_comm_v3.js）

除米大师内购外，页面还有跳转外部支付/开通页的入口：

| 方法 | 目标 | 说明 |
|------|------|------|
| `CARD.flashCalls.openVip()` | `paycenter.qq.com/qqshow/` | 开通红钻 |
| `CARD.flashCalls.openRVip(type)` | `paycenter.qq.com/qqshow/?pageshow=acct&aid=...` | 集卡页开红钻 |
| `CARD.flashCalls.vipIconClick()` | `show.qq.com/live/appspe/cardspe.html` | 红钻特权页 |
| `CARD.flashCalls.yearVipIconClick()` | `show.qq.com/show_v3.html?...itemno=5000019` | 年费红钻开通 |
| `CARD.flashCalls.toPrivilegeIndex()` | `magic_privilege.html` | 特权首页 |
| `CARD.flashCalls.showCashUsage()` | `cashusage.html` | 消费记录弹窗 |

## 6. 备注

- `session_type: "skey"` 表明使用 QQ 登录态（uin+skey）作为米大师会话凭证。
- `native_wxpay:1` 说明该版本已支持微信原生支付通道。
- 沙箱联调时 `sandbox` 参数须为 `1`。
