# 07 · 精灵系统 CARD.elf

对应文件：`card_comm_v3.js`（`CARD.elf`）

精灵（宠物）是玩家的辅助角色，通过经验升级习得/强化技能（迅捷、雷电、据守），并有专属升级弹窗。精灵需要"喂养"，饥饿会离家出走，可用商店"召回令"找回。

## 1. 技能表 `oSkillInfo`

```js
oSkillInfo: {
  //  等级: [迅捷等级, [雷电等级, 雷电数值], 据守等级]
  "1": [1, [0,   0], 0],
  "2": [1, [1, 100], 0],
  "3": [2, [1, 100], 0],
  "4": [2, [2, 500], 0],
  "5": [2, [2, 500], 3],
  "6": [3, [3,1200], 3]
}
getSkillInfo(lv)  // 返回对应等级的技能配置
```

技能解读（结合升级弹窗文案）：

| 精灵等级 | 迅捷 | 雷电 | 据守 | 解锁说明 |
|----------|------|------|------|----------|
| 1 | 1 | — | — | 初始 |
| 2 | 1 | 1（100） | — | 学会雷电技能 |
| 3 | 2 | 1（100） | — | 迅捷升到 2 级 |
| 4 | 2 | 2（500） | — | 雷电升到 2 级 |
| 5 | 2 | 2（500） | 3 | 学会据守技能 |
| 6 | 3 | 3（1200） | 3 | 迅捷 3 级、雷电 3 级 |

## 2. 经验 → 等级 `getLvInfo(iExp)`

```js
getLvInfo: function(iExp){
  var obj = {};
  if      (iExp <  350) { obj.lv=1; obj.range=350;  obj.begin=0;    }
  else if (iExp < 1050) { obj.lv=2; obj.range=700;  obj.begin=350;  }
  else if (iExp < 2150) { obj.lv=3; obj.range=1100; obj.begin=1050; }
  else if (iExp < 3600) { obj.lv=4; obj.range=1450; obj.begin=2150; }
  else if (iExp < 5400) { obj.lv=5; obj.range=1800; obj.begin=3600; }
  else                    obj.lv=6;
  return obj;   // range=当前级所需经验跨度, begin=当前级起始经验
}
```

精灵等级经验阈值：

| 等级 | 经验区间 | 跨度 |
|------|----------|------|
| 1 | 0 – 349 | 350 |
| 2 | 350 – 1049 | 700 |
| 3 | 1050 – 2149 | 1100 |
| 4 | 2150 – 3599 | 1450 |
| 5 | 3600 – 5399 | 1800 |
| 6 | ≥ 5400 | 满级 |

## 3. 升级弹窗 `showElfLvUp(elem, arg)`

根据 `arg.lv` 动态生成"精灵升级"弹窗 DOM，展示对应文案和技能图标：

- 2/5 级用 `popup_promotion`（大图样式），展示新技能图标：
  - 2 级：雷电图 `craftsmanship_03.png`（红边框）
  - 5 级：据守图 `craftsmanship_04.png`（黄边框）
- 3/4/6 级用 `popup_promotion_msg`（纯文字）。
- 弹窗有"确定"和"关闭"按钮，关闭时通过 `CARD.moduleDialogQueue` 维护弹窗队列。

文案示例：
> 恭喜您的精灵升级到 2 级，精灵学会了雷电技能！

## 4. Flash 触发入口

```js
CARD.flashCalls.showElfLvUp(newlv)
// 若已有弹窗打开则延时 2s，否则调 CARD.elf.showElfLvUp
```
