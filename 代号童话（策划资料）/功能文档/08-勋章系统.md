# 08 · 勋章 / 称号系统

对应文件：`badge_info_v3.js`（`badge_list`）、`card_comm_v3.js`（`CARD.data.getBadgeName`、`CARD.data.mapBadge`）

## 1. 数据表 `badge_list`

字段定义（表头注释）：

```
//iId, sName, iseries, iType, iActtype, iMoney, sDesc, iResInt1
```

| 下标 | 字段 | 含义 |
|------|------|------|
| 0 | `iId` | 勋章 id |
| 1 | `sName` | 勋章名（节日/套卡勋章此处常为空，动态拼接） |
| 2 | `iseries` | **勋章类型/系列**（关键分类字段） |
| 3 | `iType` | 类型 |
| 4 | `iActtype` | 触发类型 / 关联套卡 id / 状态位偏移 |
| 5 | `iMoney` | 奖励金币 |
| 6 | `sDesc` | 达成条件描述 |
| 7 | `iResInt1` | 资源整型（阈值 / 关联套卡 id） |

### 勋章类型（`iseries`，即 `badge_list[i][2]`）

| 值 | 类别 | 名称来源 | 图标 |
|----|------|----------|------|
| 1 | **等级/成就勋章** | 用 `sName` | 单图 |
| 2 | **收集成就勋章** | 用 `sName` | 单图 |
| 3 | 节日勋章（早期） | 动态金/银/铜 + 套卡名 | `_2`/`_3` |
| 4 | **套卡勋章** | 金*/银*/铜* + 套卡名 | `_2`/`_3` |
| 5 | 节日勋章 | 同 3 | 同 |
| 6 | 节日勋章 | 同 3 | 同 |
| 7 | 节日勋章（位偏移型） | 同 3 | 同 |

## 3. 勋章名解析 `CARD.data.getBadgeName`

```js
getBadgeName(iID, iRecord, live, liveEx, liveEx2, liveEx3)
```

核心逻辑（详见 [05-数据管理](05-数据管理CARD-data.md) §5）：

1. **套卡勋章（type=4）**：按 `iRecord`（1/2/3）取金*/银*/铜*，名称 = 前缀 + 对应套卡名（从 `theme_card_list` 中 `badge_list[i][4]` 查）。
2. **节日勋章（type=3/5/6/7）**：从玩家状态位 `live/liveEx/liveEx2/liveEx3` 中解析出该勋章的金/银/铜等级（每勋章 2 bit）。
   - type=7：状态在 `liveEx3`，偏移 = `cur[4]*2`。
   - `bid>=1409`：状态在 `liveEx2`。
   - `bid>=948`：状态在 `liveEx`。
   - 其余：状态在 `live`。
   - id=948 特殊跳过。
3. **其他勋章**：直接用 `badge_list[i][1]` 名称。

图标 URL：`http://appimg2.qq.com/card/img/badge/<id>`，银牌加 `_2`，铜牌加 `_3`。

## 4. 状态位编码（金/银/铜）

节日勋章的达成程度用 **2 bit** 表示：

| 值 | 等级 | 前缀 | 图标后缀 |
|----|------|------|----------|
| 0 | 未达成 | — | — |
| 1 | 金 | 金* | （无） |
| 2 | 银 | 银* | `_2` |
| 3 | 铜 | 铜* | `_3` |

多个勋章的状态位在一个整数里顺序排列，通过右移 2 位逐个取出。
