# 09 · 任务系统 CARD.mission

对应文件：`card_comm_v3.js`（`CARD.mission`）

`CARD.mission` 是新手引导 + 成长任务的**状态机**，负责判断任务状态、向服务端提交完成、处理任务奖励（金币/经验/魔力/升级）。任务分两段：**新手主线（≤ MISSION_LINE_1=19）** 走 JS 直连 CGI；**成长任务（> 19）** 由 Flash 记录状态、JS 协助推进。

## 1. 任务常量表

```js

## 2. 任务状态查询 `getMissionStatus(mission)`

- 成长任务（>19）但玩家还在主线：返回 -1（不可做）。
- 主线任务（13~19）：比对 `oMyData.missionid` 与当前 `missionStatus`。
- 其他：调 Flash `getMission()` 拿状态数组匹配。

## 3. 任务推进流程

```
checkMission(mission, param)
   │  取状态
   ├─ DOING/MISSION_DOING → doMission()      开始任务
   └─ DONE/MISSION_DONE   → completeMission() 提交完成
```

### `doMission(mission, param)`
调 CGI：`card_mission_do?curmiss=<id>&curcmd=100`
- code=0 且 mission≤19 → 转 `completeMission`
- 否则调 Flash `updateMission(mission)` 更新展示

### `completeMission(mission, param)`
调 CGI：`card_mission_complete?curmiss=<id>`，成功后：
- 更新 `oMyData.missionid`、`mana`
- 用 `updateInfo` 同步金币(`money`)/经验(`exp`)/魔力/下一任务(`nextmiss`)/下一步(`nextcmd`) 给 Flash
- **升级处理**：若返回 `lv_diff>0`
  - 非提交套卡任务 → 立即 `showLevelUp(lv, gifttype)` 弹升级奖励
  - 提交套卡任务 → 暂存到 `_mission_lvup`，稍后处理（避免与套卡弹窗冲突）

## 4. 任务巡检 `isFinishMission()`

页面加载后 `setTimeout("CARD.mission.isFinishMission()", 500)` 触发，逐项检查并自动推进可完成的任务：

| 检查 | 条件 | 动作 |
|------|------|------|
| 当前任务待提交 | `getMissionStatus(missionid) == -2` | `checkMission` |
| 卡炉已升级 | `stove.lv > 1` 且升级任务=0 | `doMission(M_STOVE_UPGRADE_1)` |
| 提交套卡 | 状态 -1/-2 | `isCollected(1)` |
| 获得称号 | 状态 0 | `isCollected(2)` |
| 开箱 | 储存箱卡数 > 20 | `checkMission(M_OPEN_BOX_1)` |
| 开交换箱 | 普通交换箱剩余槽 < 5 | `checkMission(M_OPEN_EXCHBOX_1)` |
| 达到 5 级 | `lv >= 5` | `checkMission(M_REACH_LV5_1)` |
| 达到 10 级 | `lv >= 10` | `checkMission(M_REACH_LV10_1)` |

## 5. 套卡数校验 `isCollected(type)`

调 CGI `card_mini_get?uin=<uin>` 拿到玩家各套卡收集数，累加：
- `type=1` 且 total>0 → 提交套卡任务 `SUBMIT_COLLECT_1`
- `type=2` 且 total≥5 → 称号任务 `M_GET_TITLE_1`

结果缓存到 `_total`、`_bFlag`，避免重复请求。

## 6. 相关服务端 CGI

| CGI | 作用 |
|-----|------|
| `card_mission_do` | 开始任务 |
| `card_mission_complete` | 完成任务领奖 |
| `card_mini_get` | 查询套卡收集数 |
| `card_user_levelup_bonus` | 查询升级奖励（`CARD.getLevelUpBonus`） |

## 7. 任务弹窗入口

| 方法 | 说明 |
|------|------|
| `CARD.flashCalls.showMissionV3()` | 主任务面板 `mission_v3.html` |
| `CARD.flashCalls.showDailyMission(uin)` | 每日任务 `dailymission.html` |
| `CARD.flashCalls.showMonthMission(uin)` | 月度任务（仅埋点） |
| `CARD.flashCalls.showMission(0,0)` | 新手任务（`reg=1` 时触发） |
