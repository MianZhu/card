# 10 · 数据表结构（卡片 / 套卡 / 合成 / 礼包）

对应文件：`card_info_v3.js`（46909 行，四大数据表）、`badge_info_v3.js`（勋章表见 [08](08-勋章系统.md)）

`card_info_v3.js` 是全游戏的静态配置数据，含四张表。每张表都是二维数组，加载后由 `CARD.data` 建成 id 映射（见 [05](05-数据管理CARD-data.md)）。

---

## 1. 合成配方表 `theme_compose_list`

**位置**：文件开头。**表头**：

```
//theme_id, state, cardtar, card1, card2, card3, [time]
```

| 下标 | 字段 | 含义 |
|------|------|------|
| 0 | `theme_id` | 所属套卡主题 |
| 1 | `state` | 状态（1=启用） |
| 2 | `cardtar` | **合成目标卡 id**（`mapCompose` 的键） |
| 3~5 | `card1/2/3` | 三张材料卡 id |
| 6 | `time` | 炼制耗时（秒） |

示例：

```js
[45,1,42,41,40,43,14400]   // 套卡45，用卡41+40+43 炼出卡42，耗时 14400s(4h)
[55,1,88,85,84,100,7200]   // 用 85+84+100 炼出 88，耗时 7200s(2h)
```

> 炼制机制：把 3 张材料卡放进卡炉，等待 `time` 秒后取出目标卡。魔火道具可缩短时间（见魔力/魔火）。耗时常见档位：3600(1h)、7200(2h)、14400(4h)、21600(6h)、86400(24h) 等。

## 2. 套卡主题表 `theme_card_list`

**表头**（两行）：

```
//theme_id, theme_name, theme_Difficulty, theme_PublishTime, theme_PickRate,
//  theme_Enable, theme_Prize, theme_Score, theme_color, gift, text,
//  [card1_id,..,cardn_id], theme_type, version, time, offtime, flash_src_tid
```

| 下标 | 字段 | 含义 |
|------|------|------|
| 0 | `theme_id` | 套卡 id |
| 1 | `theme_name` | 套卡名称 |
| 2 | `theme_Difficulty` | 难度系数（1~5，UI 里按难度分组） |
| 3 | `theme_PublishTime` | 发行时间戳 |
| 4 | `theme_PickRate` | 抽取概率 |
| 5 | `theme_Enable` | 是否启用 |
| 6 | `theme_Prize` | 集齐奖励（金币） |
| 7 | `theme_Score` | 集齐积分 |
| 8 | `theme_color` | 主题字体色（`0` 用默认，否则 `#RRGGBB`） |
| 9 | `gift` | 关联 QQ 秀礼包 id（可含性别 `M_/F_` 分支） |
| 10 | `text` | 文案 |
| 11 | `[...]` | **成员卡 id 数组** |
| 12 | `theme_type` | **位标记 bitmap**：`&0x01` 绝版 / `&0x08` 闪卡 |
| 13 | `version` | 资源版本号（拼图片 URL 的 `ver`） |
| 14 | `time` | 上架时间 |
| 15 | `offtime` | **下架时间戳**（`getThemeOffTime`） |
| 16 | `flash_src_tid` | 闪卡源主题 id（`mapFlashTheme` 的键） |

示例：

```js
[40,'时尚男套装 ',1,1251970023,0,1,100,200,0xffffff,'24','',
 [66,65,64,39,38,37,36,35,33,32,31,30,29], 0,4,1309831119,0,0,1,0]
// 套卡40，难度1，集齐奖100金币/200分，关联礼包24，含13张成员卡
```

## 3. 礼包 / QQ 秀表 `gift_list`

**表头**：

```
//gift_id, gift_type, szTYPE_ID, gift_name
```

| 下标 | 字段 | 含义 |
|------|------|------|
| 0 | `gift_id` | 礼包 id |
| 1 | `gift_type` | 类型 |
| 2 | `szTYPE_ID` | QQ 秀商品类型 id（字符串） |
| 3 | `gift_name` | 名称 |

示例：`[24,1,'454051','modify']`。

集齐套卡后根据 `theme_card_list[i][9]` 关联的 gift，通过 `CARD.getGiftInfo(themeid)` 找到对应 QQ 秀礼包（含按性别 `M/F` 分支的逻辑）。

## 4. 卡片表 `card_list`

**表头**：

```
//card_id, theme_id, CardName, Price, Type, PickRate, Enable, version, time, item_no, [mana]
```

| 下标 | 字段 | 含义 |
|------|------|------|
| 0 | `card_id` | 卡片 id |
| 1 | `theme_id` | 所属套卡 |
| 2 | `CardName` | 卡片名称 |
| 3 | `Price` | 价格（金币） |
| 4 | `Type` | 类型 |
| 5 | `PickRate` | 抽取概率 |
| 6 | `Enable` | 是否启用 |
| 7 | `version` | 资源版本（拼图片 URL 的 `ver`） |
| 8 | `time` | 时间 |
| 9 | `item_no` | 商品编号 |
| 10 | `[mana]` | 魔力相关数组 |

示例：

```js
[29,40,'城市街道',40,1,0,1,1,0,1027529,[0]]  // 卡29 属套卡40，售价40金币
[30,40,'搞怪笑脸',10,0,0,1,1,0,1011379,[0]]
```

## 5. 图片资源约定

| 资源 | URL 模板 |
|------|----------|
| 卡片小图 | `/card/img/card/<id>_56?ver=<version>` |
| 卡片大图 | `/card/img/card/<id>?ver=<version>` |
| 套卡背景 | `/card/img/theme/<theme_id>?ver=<version>` |
| 套卡大 logo | `/card/img/theme/<theme_id>_big_logo?ver=<version>` |
| 套卡小 logo | `/card/img/theme/<theme_id>_logo?ver=<version>` |
| 套卡博物馆图 | `/card/img/theme/<theme_id>_museum` |
| 勋章图 | `/card/img/badge/<id>`（银 `_2`、铜 `_3`） |

`ver` 版本号用于资源更新时的缓存刷新。
