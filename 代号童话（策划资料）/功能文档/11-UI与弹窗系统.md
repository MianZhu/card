# 11 · UI 与弹窗系统

对应文件：`card_comm_v3.js`（`CARD.ui`、`CARD.flashCalls`、`CARD.moduleDialogQueue`、`CARD.dialog`、`CARD.showModalDialog`）

游戏所有 HTML 界面都是**模态弹窗**，由 Flash 本体触发（`CARD.flashCalls.*`），经统一的弹窗封装打开。本文档覆盖弹窗基础设施；具体业务弹窗入口见 [14-活动与礼包入口](14-活动与礼包入口.md)。

## 1. 模态弹窗 `CARD.showModalDialog(sUrl, oFeatures, sMode)`

统一的弹窗入口，兼容 Qzone / QQ 秀两种宿主：

```js
showModalDialog(sUrl, oFeatures, sMode){
  CARD.moduleDialogQueue.setDialogOpened();
  oFeatures.mode = oFeatures.mode || 0;
  if (oFeatures.mode == 1){          // mode=1：用 QSFL.dialog.messageBox（带遮罩窗口）
    QSFL.dialog.messageBox(sUrl, {width, height, left, top, maskWindow}, {}, 0);
  } else {                           // mode=0：走 SNS 适配层弹窗
    QSFL.sns.getApplicationWindow().QSFL.sns.showModalDialog(sUrl, [], oFeatures, "", sMode, _bQzone);
  }
}
```

`oFeatures` 参数：`w`(宽) `h`(高) `l`(左) `t`(上) `mode`(0/1)。

关闭：`CARD.closeDialog(iCheckTime)` — 关闭当前弹窗并检查队列。

## 2. 弹窗队列 `CARD.moduleDialogQueue`

避免多个弹窗同时弹出打架，用队列串行化：

```js
CARD.moduleDialogQueue = {
  dialogQueue: [], opened: false,
  pushOpenPage(url, features, mode){    // 入队；若当前无弹窗则立即打开
    dialogQueue.push({url, features, mode});
    if (!opened){ page = popOpenPage(); CARD.showModalDialog(...); }
  },
  closeCheckDialogQueue(iPopTime){      // 关闭后检查队列，延时弹出下一个
    if (queue.length && !opened) setTimeout(打开下一个, iPopTime);
  }
}
```

- `setDialogOpened()` / `setDialogClosed()` 维护 `opened` 标记。
- 升级奖励、登录奖励、主题变更等"被动弹窗"都走 `pushOpenPage` 排队。

## 3. 通用提示弹窗

### `CARD.ui.showErrDlg(elem, arg)`
最常用的提示/确认弹窗。`arg` 可配置：`msg`、`title`、`onOkDescribe`(确定按钮文案)、`cancel`(是否显示取消)、`onOK`/`onClose`/`onBtn2` 回调、`mask`(遮罩)、`width/height/left/top`。

用例：精灵饿走、加载失败去小诊所、魔力不足、被封号提示等。

### `CARD.dialog.showMessage(obj)`
轻量提示弹窗（`popup_module1` 样式），默认文案"当前操作用户过多，请稍候重试"。`closeMessage()` 关闭。

## 4. 验证码弹窗 `CARD.ui.showVerifyDlg(code, elem, arg)`

防外挂/防刷验证码。验证码图来自 `ptlogin2.qq.com/getimage?aid=10000101`。

- 输入必须 4 位（`asclen()==4`）。
- `changePic()` 换一张。
- 由 `CARD.handleVerifyPage(code, ...)` 分发：
  - `-1103/-1104/-1105` → 弹验证码
  - `-1107` → `denyNaughtyUser`（封号提示，见 [12](12-统计与安全上报.md)）

## 6. 主题选择器 `CARD.ui.showSelectTheme` / `showSelectThemeDetail`

集卡/炼卡时选择套卡主题的复杂弹窗，把套卡按 **发行套卡 / 绝版套卡 / 闪卡** 三类 Tab 展示，每类内再按难度系数 1~5 分组。

- 统计各类总数：遍历 `theme_card_list`，用 `checkFlashCard`/`checkJbCard`（bitmap）分类。
- 我的收集数：调 CGI `card_mini_get?uin=<uin>` 拿 `mapMyMiniCol`，已集齐的加 `ico_tick` 勾标记。
- `arg.type` 控制显示哪些 Tab（0 全部 / 1 只绝版 / 2 排除闪卡 / 3 只闪卡 / 4 只发行）。
- `changeThemeType(type, elem)` 切换 Tab。
- 排除 `PROPS_THEME_ID`(111) 道具主题。

## 7. 加载遮罩

```js
CARD.ui.waitStart()  // 显示遮罩 + loading
CARD.ui.waitEnd()    // 隐藏
```

## 8. Flash → JS 弹窗分发 `CARD.flashCalls.showPopUp(sType)`

Flash 用字符串类型触发对应弹窗：

```js
fMap = {
  "showMyCards"    : showBox,          // 卡箱
  "showCombinCards": showStoveV3,      // 卡炉
  "stealCardDo"    : showStealStoveV3, // 偷炉
  "showRuneShop"   : showShop,         // 符文商店
  "showMarket"     : showMarket,       // 市场
  "showNoticePanel": showNotice,       // 公告
  "showCardSet"    : viewCollec,       // 套卡收藏
  "showStoveUpgrade": showStoveUpgrade // 卡炉升级
}
```
