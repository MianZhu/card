# 12 · 统计、测速与安全上报

对应文件：`魔法卡片-QQ秀.html`（浏览器/Flash 上报、测速）、`card_comm_v3.js`（PGV、防外挂、崩溃兜底）、`config2.js`（反劫持白名单）、`tcss.ping.js`

## 1. 浏览器 & Flash 版本上报（HTML 内联）

页面加载即执行 `browserAndFlashLogUp()`，采集环境信息上报到 **阿塔（ATTA）日志平台**：

```js
function browserAndFlashLogUp(){
  var browserType = getBrowserType(getBrowser().type);  // 浏览器类型码
  var flashVersion = getFlashVersion() || "0";          // Flash 版本
  var uin = getCookie("uin");  // 去掉前导 'o'
  bodyData = "attaid=0dc00067281&token=7862796798&BrowserType=..&BrowserVersion=..&FlashVersion=..&skey=..&uin=..";
  attaLogUp(bodyData);   // POST https://h.trace.qq.com/kv
}
```

浏览器类型码（`getBrowserType`）：

| 码 | 浏览器 | 码 | 浏览器 |
|----|--------|----|--------|
| 1 | IE | 6 | Edge |
| 2 | Chrome | 7 | QQ 浏览器 |
| 3 | Firefox | 8 | 微信内置 |
| 4 | Opera | 9 | 360 |
| 5 | Safari | 0 | 未知 |

`getBrowser()` 通过 UA/特征检测浏览器与版本；`getFlashVersion()` 通过 ActiveX（IE）或 `navigator.plugins`（其他）读 Flash 版本。

var iTimePoint_0 = new Date();   // 起点

function cardTimeReport(vTimePoints_1){

## 3. PGV 点击/曝光埋点

腾讯 PGV（页面统计）系统，虚拟域 `card.show.qq.com`：

```js
CARD.initPGV()             // 加载 ping.js 并 pgvMain 初始化
CARD.sendPGV(hottag)       // 上报一个热点 tag（pgvSendClick）
CARD.getPGVJs(fn)          // 懒加载 ping.js 后执行
```

- 全项目大量调用 `CARD.sendPGV("ISD.QQshow.Card.xxx")` 记录各功能点击。
- `CARD.flashCalls.sendPGV(CORD)` 内做了一层 tag 名映射（如 `happygift_refresh_value` → `FlaColl_happygift_refresh_value`），供 Flash 上报活动埋点。

## 4. 反外挂 / 防刷

### 验证码校验
频繁操作会触发验证码（`CARD.ui.showVerifyDlg`，见 [11](11-UI与弹窗系统.md)）。错误码：
- `-1103/-1104/-1105`：需输入验证码
- `-1107`：判定使用外挂

### 封号提示 `denyNaughtyUser(imSenconds)`
检测到多次使用外挂时，弹窗告知封停 5 天，展示恢复时间：

> 您的账号已被系统检测出多次使用外挂，系统将关闭您的魔法学院 5 天。您的帐号可于 `<恢复时间>` 恢复登录。若再次检测到使用外挂，将给予封号甚至永久封号处理。

确认后跳转 `qbar.qq.com/magiccard`。

### g_tk 令牌
所有 CGI 请求附加 `g_tk = hash(skey)` 防 CSRF（见 [02](02-登录与SNS适配.md) §2）。

## 5. 崩溃 / 网络异常兜底 `CARD.CRASH`

```js
CARD.CRASH.crashProof(){
  alert("由于网络不通，魔法学院暂时休学……");
  location.href = "register_v3.html?crashed=1";
}
```

Flash 通过 `CARD.flashCalls.crashProof()` 触发。
