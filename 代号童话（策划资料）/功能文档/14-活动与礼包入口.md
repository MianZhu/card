# 14 · 活动、礼包与运营入口

对应文件：`card_comm_v3.js`（`CARD.flashCalls` 中的活动方法、`CARD.showPresent`、`CARD.getGiftInfo`）

游戏内嵌大量节日/运营活动，绝大多数是通过 `CARD.flashCalls.*` 打开对应的活动 HTML 弹窗，并用 `sendPGV` 埋点。这些活动多为**限时**，页面 URL 带时间戳参数（如 `t=20120606`）。

## 1. 礼包系统

### 集齐套卡送 QQ 秀 `CARD.getGiftInfo(themeid)`
集齐套卡后，根据套卡配置 `theme_card_list[i][9]`（gift 字段）找对应 QQ 秀礼包：

```js
getGiftInfo(themeid){
  var str = CARD._data_theme[themeid][9].split('|');
  if (str.length == 2){          // 按性别分支：M_xxx | F_xxx
    var sex = CARD._sex == 1 ? 'M' : 'F';
    id = (对应性别项).split('_')[1];
  } else id = str[0];
  // 在 gift_list 中匹配 id 返回礼包
}
```

### 等级/临时礼包 `showGiftPackage(giftlv, gifttemp)`
```js
// giftlv>0  → gift_v3.html?type=1&lv=<giftlv>  等级礼包
// gifttemp>0 → gift_v3.html?type=2&lv=<gifttemp> 临时礼包
```

### 直购礼包 `showFastBuy1(type)`
`live/direct_buy_v3.html?type=<type>`，type 231/232/233 为限定活动礼包（如四月红包）。

### 礼包确认 `showGiftConfirm(type, p1, p2, p3)`
`gift_confirm.html`，type 1~4 分别对应不同确认场景。

| 方法 | 说明 |

## 5. 免费 QQ 秀领取

```js
CARD.flashCalls.showFreeGiftPage(num)
// num=0 → index.htm?appid=365          免费礼列表
// num=1 → index.htm?appid=365&page=receive  领取页
```

初始化时若 hash 参数 `activepgv=Freegifts` 会自动弹出。

## 6. 魔力 / 魔火（炼卡加速）

`showManaNotEnough(type, page, mana)`：魔力不足提示，引导兑换魔力。魔火类型：

| type | 名称 |
|------|------|
| 1 | 一昧真火 |
| 9 | 烈地魔火 |
| 10 | 紫天魔火 |

魔火可缩短炼卡时间。相关弹窗：`showBottleMarket()`（魔力瓶市场 `market_v3.html?bottle=1`）。
