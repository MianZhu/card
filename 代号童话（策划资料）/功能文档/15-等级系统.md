# 15 · 等级系统 CARD.LEVEL

对应文件：`card_comm_v3.js`（`CARD.LEVEL` 对象）

玩家等级由累计经验（Score）决定。等级用于解锁功能、决定卡箱格子数、触发升级礼包（见文档 14）。

## 1. 经验阈值表 `LEVEL_SCORE`

```js
CARD.LEVEL = {
  // 下标 = 等级-1，值 = 升到该等级所需的累计经验
  LEVEL_SCORE: [
    0, 100, 300, 600, 1000, 1500, 2100, 2800, 3600, 4500,   // Lv1~10
    5500, 6600, 7800, 9100, 10500, ...                        // Lv11+
  ],
  ...
}
```

> 数组为等差递增（每级增量 +100、+200、+300…），呈二次增长。实际项数决定封顶等级。

## 2. 经验→等级 `getLevel(score)`

```js
getLevel: function(score){
  var lv = 1;
  for (var i = 0; i < this.LEVEL_SCORE.length; i++){
    if (score >= this.LEVEL_SCORE[i]) lv = i + 1;
    else break;
  }
  return lv;
}
```

- 线性扫描阈值表，返回不超过 `score` 的最高档位。
- 与**精灵等级**（文档 07 `CARD.elf.getLvInfo`）是两套独立体系：本表是**玩家账号等级**，精灵表是**familiar 等级**。

## 3. 等级的用途

| 场景 | 关联逻辑 |
|------|----------|
| 卡箱格子数 | `CARD.user.getOpenSlotNum()` 按等级开放更多卡槽 |
| 升级礼包 | 升级触发 `flashCalls.showLevelUp(lv, gifttype)`（文档 14） |
| 等级勋章 | `badge_list` 中 `iseries=1` 的成就（法师学徒 Lv5…，见文档 08） |
| 升级奖励查询 | CGI `card_user_levelup_bonus` → `CARD.getLevelUpBonus` |
| Flash 显示 | Flash 侧读取等级渲染头像框/称号 |

## 4. 数据来源

等级/经验由服务端在用户注册和每次操作后下发，前端通过 `CARD._user`（初始化数据）与 Flash 回调 `updateInfo` 同步。前端不自行计算经验增量，只做 `score → level` 的展示换算。
