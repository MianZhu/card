# 16 · 社交、记录与消息

对应文件：`card_comm_v3.js`（`CARD.ptp`、`CARD.FEED`、`CARD.flashCalls` 社交入口）、`魔法卡片-QQ秀.html`（record_model 记录页签）

魔法卡片是社交卡片游戏，社交能力包括：好友间偷卡/送礼、点对点消息、操作记录流、私信/公告。

## 1. 点对点消息 CARD.ptp

用于**好友互动结果的异步通知**（偷卡成功、被偷、赠礼到账等）。

```js
CARD.ptp = {
  check: function(){
    // 拉取待处理的 ptp 消息：CGI card_ptp_get
    // 有消息则 callback 逐条处理
  },
  callback: function(oData){
    // 根据 msg type 分发：
    //   偷卡通知 → 弹提示 / 更新卡箱
    //   赠礼通知 → 入账并提示
    //   系统通知 → showTips
  }
}
```

- 登录初始化后由 `initIndex` 触发 `CARD.ptp.check()`。
- 消息载体为服务端队列，前端轮询消费。

## 2. 操作记录流 record_model（HTML 页签）

主页 `魔法卡片-QQ秀.html` 底部有记录区，三个页签切换：

| 页签 DOM | 名称 | 内容 | CGI |
|----------|------|------|-----|
| `box_record` | 卡箱记录 | 卡片进出、获得来源 | `card_record_box_get` |
| `stove_record` | 卡炉记录 | 炼卡投料/产出/被偷 | `card_record_stove_get` |
| `mana_record` | 魔力记录 | 魔力获取/消耗 | `card_record_mana_get` |

页签切换为纯前端 `class` 切换 + 懒加载对应 CGI 列表并渲染。

## 3. FEED 动态流 CARD.FEED

向 Qzone 好友动态推送游戏事件（集齐套卡、升级、获得绝版卡等），用于拉活/裂变：

```js
CARD.FEED = {
  send: function(type, data){
    // 组装 feed 内容 → sns.qzone.qq.com/cgi-bin/feeds/...
  }
}
```

与 `SendShareGift` / `shareInQzone`（文档 14）配合，是社交传播链的一环。

## 4. 好友互动入口（flashCalls）

| 方法 | 说明 | CGI |
|------|------|-----|
| `showStealStoveV3(uin)` | 偷好友卡炉里的卡 | `card_stove_stealcard_get` |
| `showBox(uin)` | 查看（好友）卡箱 | `card_box_get` |
| `showMarket()` | 交易市场（好友间买卖） | `card_market_*` |
| `SendShareGift(obj)` | 集卡后向好友撒礼 | `fusion2 sendRequest` |
| `showPresent()` | 收礼弹窗 | `present.html` |

偷卡有保护机制（`denyNaughtyUser` 拦截异常账号、频率限制）。

## 7. 社交数据同步

好友操作结果通过两条路径回到本地：
1. **实时**：Flash 调 CGI 后拿到结果 → `updateCardWith`/`updateInfo` 更新卡箱。
2. **异步**：`CARD.ptp.check()` 轮询离线通知（好友在你离线时的操作）。
