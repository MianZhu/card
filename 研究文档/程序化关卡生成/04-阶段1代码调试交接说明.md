## 4. 当前代码职责

### RoomPort

预期职责：

- 继承 `Marker2D`，使用 `@tool` 和 `class_name RoomPort`；
- 定义 `NORTH/EAST/SOUTH/WEST` 四个逻辑方向；
- 保存接口所在局部大格、接口规格和边界范围；
- 判断两个接口的方向和规格是否兼容；
- 在编辑器中绘制方向箭头；
- 不生成门，不修改碰撞，不连接房间。

核心接口：

```gdscript
func direction_vector() -> Vector2i
func opposite_direction() -> Direction
func edge_end() -> int
func has_valid_edge_range() -> bool
func is_compatible_with(other: RoomPort) -> bool
```

### RoomTemplate

预期职责：

- 继承 `Node2D`，使用 `@tool` 和 `class_name RoomTemplate`；
- 保存房间 ID、类别、占用大格、抽取权重和深度限制；
- 要求 `(0,0)` 是实际占用的锚定大格；
- 从直接子节点 `Ports` 收集 `RoomPort`；
- 返回验证错误列表；
- 在编辑器中绘制房间占用大格轮廓；
- 不实例化房间，不访问 UI，不执行随机生成。

核心接口：

```gdscript
func get_ports() -> Array[RoomPort]
func has_occupied_block(block: Vector2i) -> bool
func validate_template() -> PackedStringArray
```

## 5. 当前验证规则

测试至少覆盖：

- 逻辑方向向量与相反方向；
- 方向相反、规格相同的接口兼容；
- 合法 T 形房间通过；
- 重复占用大格失败；
- 缺少锚定大格 `(0,0)` 失败；
- 接口位于未占用大格失败；
- 接口朝向另一个已占用大格时失败；
- 接口范围超过 16 小格边界时失败；
- 同一大格、同一边界上的两个接口范围重叠时失败。

## 7. 调试优先级

### 第一优先：解析与类型

检查 Godot 4.7 是否接受：

- `RoomPort.Direction` 作为参数和返回值类型；
- `Dictionary[Vector2i, bool]` 类型声明；
- `Array[RoomPort]` 和 `child as RoomPort`；
- `@export_range` 与枚举导出变量；
- `class_name` 注册缓存是否需要重启编辑器或删除 `.godot/`；
- `SceneTree` 测试脚本中的 `class_name` 是否必要。

发生 `Identifier not declared` 时，遵守项目规范：先重启 Godot，再删除 `.godot/` 缓存；不要用脚本 `preload` 绕过 `class_name`。

### 第二优先：错误列表是否正确传递

重点实测以下结构是否会修改调用者持有的 `PackedStringArray`：

```gdscript
func validate_template() -> PackedStringArray:
    var errors := PackedStringArray()
    _validate_room_metadata(errors)
    return errors
```

如果 Godot 4.7 对 `PackedStringArray` 参数采用写时复制，辅助函数中的 `append()` 可能无法回写调用者。不要猜测，应使用最小测试确认。

如果确有问题，推荐二选一：

1. 辅助函数各自返回 `PackedStringArray`，调用者用 `append_array()` 合并；
2. 内部验证统一使用 `Array[String]`，最后转换为 `PackedStringArray`。

优先选择代码最清晰、测试最直接的方式。

### 第三优先：接口边界语义

当前匹配规则要求两个接口的 `edge_start` 和 `edge_length` 完全相同。调试时必须确认统一语义：

- `NORTH/SOUTH` 边的偏移沿逻辑 `+X` 方向增加；
- `EAST/WEST` 边的偏移沿逻辑 `+Y` 方向增加；
- 两个相对边都使用世界一致的逻辑轴，不按每条边的顺时针方向重新计数；
- 因此相邻房间接口匹配时不需要镜像 `edge_start`。

如果实际房间制作选择“沿外轮廓顺时针计数”，匹配公式必须改成镜像范围。两套约定不能混用。

### 第四优先：编辑器调试绘制

编辑器占用大格和接口箭头只是辅助显示，不参与生成正确性。需要确认：

- 箭头方向与项目 TileMap 的实际斜视角投影一致；
- 大格轮廓与 `16×16` 小格范围一致；
- 调试绘制不会在运行时出现；
- 修改导出属性后能及时 `queue_redraw()`。

绘制方向错误不应通过修改逻辑方向定义来修复，应只调整显示转换。
